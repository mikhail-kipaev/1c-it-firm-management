# Учебный проект: Конфигурация «Управление ИТ-фирмой» 

Данный проект разработан в рамках курса «1С-программист: расширенный курс» (Нетология). 
Конфигурация создана с нуля и предназначена для автоматизации учета торговых операций и услуг ИТ-компании.

## Реализованный функционал:

*   **Архитектура и справочники:** Создана структура метаданных, разделенная на подсистемы (`Настройки`, `Сделки`, `Деньги`). Реализована иерархия номенклатуры, перечисления типов и ставок НДС.
*   **Ценообразование:** Разработаны документы `УстановкаЦен` и `УстановкаСкидок`, которые делают движения по периодическим регистрам сведений.
*   **Учет операций:** Реализованы документы `ПоступлениеТоваровИУслуг` и `РеализацияТоваровИУслуг`.
    *   В формах реализован автоматический пересчет сумм и НДС (расчет «в том числе»).
    *   Списание товаров происходит по средней себестоимости с контролем остатков (документ не проводится при недостатке товара).
*   **Отчетность (СКД):** Разработаны три отчета на Системе компоновки данных. В отчете `ДоходыИРасходы` реализовано объединение двух разных регистров (`ОБЪЕДИНИТЬ ВСЕ`) для расчета прибыли. В отчете `ДвижениеТоваров` настроено отключение суммирования количественных итогов в иерархии.
*   **Права доступа:** Настроена ролевая модель. Доступ к ценообразованию ограничен ролью `ПолныеПрава`.

## Как запустить
1. Скачайте файл `IT_Firm_Config.cf` из репозитория.
2. Создайте новую пустую информационную базу (без конфигурации).
3. В Конфигураторе выберите `Конфигурация -> Загрузить конфигурацию из файла` и укажите скачанный файл.
4. Обновите конфигурацию базы данных (F7).
